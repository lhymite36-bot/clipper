Sample clips produced by an end-to-end test live here on the machine
that ran the test (`/workspace/clipper/samples/` on the build box).

MP4 outputs are not committed (they are large and easy to regenerate).
See `SOURCE.txt` for the license of the test footage.

The test source is a 90-second excerpt of *Big Buck Bunny* by the
Blender Foundation, Creative Commons Attribution 3.0:
https://peach.blender.org/about/
https://archive.org/details/BigBuckBunny_328

```
clipper /path/to/bbb_short.mp4 --count 2 --out samples
```
